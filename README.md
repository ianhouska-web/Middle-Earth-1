# JavaScript Practice Repository

This repository contains small JavaScript example files organized by topic.

## Structure

- `basics/` — simple JavaScript fundamentals like arrays, strings, numbers, booleans, objects, and conversions.
- `classes/` — class examples.
- `control-flow/` — conditionals and loops.
- `data-structures/` — Map and Set examples.
- `formatting/` — date and number formatting examples.
- `json/` — JSON stringify/parse examples.
- `docs/` — sample text file.
- `practice.js` — runner file that executes all example files.

## How to use

1. Open a terminal in this repository.
2. Run a single file directly with Node:

```bash
node basics/arrays.js
```

3. Run the practice runner to execute all examples:

```bash
node practice.js
```

## Notes

- Most files already include a small practice example at the bottom.
- If you want to practice a topic, open the matching file and add your own `console.log()` or code block.
- `practice.js` runs the files in sequence and helps verify they all execute.
